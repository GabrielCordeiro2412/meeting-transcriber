# Roadmap

This roadmap reflects the current `local-first` direction of Meeting Recorder.

## Current baseline

- Native macOS menu bar app
- Floating widget
- Local recording and local history
- OpenAI processing using the user’s own API key
- No login
- No cloud sync

## Near-term priorities

1. Search in local history
2. Better export flows:
   - Markdown
   - TXT
   - PDF
3. More robust reprocessing from local files
4. Better transcript cleanup and chunk deduplication
5. Summary templates:
   - daily
   - 1:1
   - planning
   - sales
6. Custom vocabulary:
   - names
   - acronyms
   - technical terms
7. Action items with richer structure
8. Better local editing experience for notes and transcript

## Mid-term ideas

1. Realtime preview notes during recording
2. iPhone companion focused on capture and review
3. Apple Watch companion focused on controls and status
4. Smarter post-processing for long meetings

## Non-goals for this repository direction

- user accounts
- remote persistence
- team collaboration
- centralized billing
- hosted SaaS infrastructure
